# Script

**Category:** Technology

## Plain English

The programming language that Bitcoin uses to define how transactions work - what conditions must be met for Bitcoin to be spent.

## Analogy

Think of Bitcoin Script as a set of rules written on a contract. Instead of "Alice sends Bitcoin to Bob," the script might say "Bob can only spend this Bitcoin if he provides a signature that proves he has the private key." Bitcoin runs these scripts to validate every transaction.

## In Context

*"Multisig wallets use Script to require multiple signatures before Bitcoin can be spent."*

**What this means:** Bitcoin Script is powerful enough for advanced features like multisig, timelocks, and atomic swaps, but limited enough to prevent infinite loops and attacks.

## Why It Matters

Script is what makes Bitcoin programmable. Without it, Bitcoin would only be simple point-to-point transactions. Script enables sophisticated features like payment channels and multi-signature security.
