# Timelock

**Olukongo:** Community

## Plain English

Taproot ni upgrade ya Bitcoin eyakholekha mu mwaka kwa 2021. Yakhola transactions shibe nende obusisi bungi, fees shikhung'ana, kandi yanyolesia smart contracts shikhongo shikore shinga okhulolesibwa khu blockchain.

## Olulinganisho

Imbere wa Taproot, buli muntu yanyala okhulola ebirimo bya transaction khu blockchain, linga okhulola ebiri omu bahasha mbere yitumwa. Taproot ibisibanga ebirimo ebyo, nikwo omutumi nende omunyooli bonyene bamanya ebiri omunda. Abandi balolanga transaction ya bulayi buterefu.


## Mu Mbeele

*"Taproot addresses shitanjikha nende 'bc1p', kandi shili nende obusisi okhushila addresses sha bulayi"*

**Amakulu kwakwo:** Noutuma Bitcoin khu Taproot address, network yimanyanga mbu transaction yakholekha, halali shiyinyala okhulola ebirimo byayo. Eno ikhung'ania fees kandi transaction yiba nditi.

## Habwaki ni yákamaro

Taproot ni imwe khu upgrades shikhongo sha Bitcoin okhurula khu SegWit. Yongeresa obusisi shinga okwongera obunene bwa blockchain. Kandi yakhola smart contracts shikhongo shinga atomic swaps nende payment channels shikore bulayi.
