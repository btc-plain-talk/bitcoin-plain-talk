# Derivation Path

**Ẹ̀ka:** Technology

## Ìtumọ̀ Rọrùn

Derivation Path jẹ́ ọ̀nà ìtọ́kasí tó ń sọ fún HD Wallet gangan bó ṣe máa ṣe ìdásílẹ̀ private key tàbí address kan láti inú seed phrase, nípa lílo ìlànà nọ́mbà tó jẹ́ àgbáyé.

## Àkàwé

Ronú pé o wà nínú ilé-ìkàwé ńlá kan tí a ṣètò sí orí ilẹ̀, shelf, àti nọ́mbà ibi tí ìwé wà. Seed phrase náà dàbí gbogbo ilé-ìkàwé náà, tó ní gbogbo àwọn ìwé inú rẹ. Derivation Path sì dàbí àdírẹ́sì tó ń sọ fún ọ pé, "Lọ sí ilẹ̀ yìí, shelf yìí, kí o sì mú ìwé tó wà ní ibi yìí." Láìsí ọ̀nà ìtọ́kasí yẹn, o lè wá ibi tí kò tọ́, kó sì dà bí ẹni pé ìwé náà kò sí.

## Ní Àpẹẹrẹ

*"Wallet yìí ń lo Derivation Path m/84'/0'/0' fún àwọn Native SegWit addresses"*

**What this means:** Àwọn nọ́mbà wọ̀nyí jẹ́ ọ̀nà àgbékalẹ̀ tí wallet ń tẹ̀lé láti ṣẹ̀dá ẹgbẹ́ kan pàtó ti Bitcoin addresses. Nígbà tí o bá fẹ́ tún wallet rẹ ṣe nínú software mìíràn, lílo Derivation Path tó tọ́ ṣe pàtàkì. Bí o bá lo ọ̀nà tó kò tọ́, wallet náà lè ṣẹ̀dá àwọn addresses míì tó yàtọ̀, ó sì lè dà bí ẹni pé wallet rẹ ṣófo, bí ó tilẹ̀ jẹ́ pé bitcoin rẹ ṣì wà lábẹ́ Derivation Path tó tọ́.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Bí o bá tún seed phrase rẹ ṣe nínú wallet app míì pẹ̀lú Derivation Path tó kò tọ́, ó lè dà bí ẹni pé gbogbo bitcoin rẹ ti pàdánù. Ṣùgbọ́n ní òótọ́, owó náà ṣì wà ní ààbò; wallet náà kàn ń wò ó ní ibi tí kò tọ́. Mímọ ohun tí Derivation Path túmọ̀ sí máa ń ran ọ́ lọ́wọ́ láti yàgò fún ìbànújẹ tàbí ìbẹ̀rù, kí o sì mọ ohun tó yẹ kí o ṣàyẹ̀wò nígbà tí o bá ń tún wallet ṣe.
