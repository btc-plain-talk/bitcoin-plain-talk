# Hásì Ìṣirò

**Ẹ̀ka:** Ìmọ̀-ẹrọ

## Ìtumọ̀ Rọrùn

Hásì ìṣirò jẹ́ iṣẹ́ ìṣírò kan tí ó lè gba ohunkóhun gẹ́gẹ́ bí ohun èlò; ọ̀rọ̀ kan, gbolohun kan, tàbí àkọsílẹ̀ gbogbo ìṣòwò, kí ó sì yí i padà sí okun lẹ́tà àti nọ́mbà tó ní gígùn kan ṣoṣo. Bí o bá yí àmì tàbí lẹ́tà kan péré nínú ohun èlò náà padà, ohun tí ó jáde náà yóò yàtọ̀ pátápátá.

## Àkàwé

Ronú nípa ẹ̀rọ kan tí o lè fi eyikeyi ìwé sínú rẹ, bóyá ọ̀rọ̀ kan ṣoṣo tàbí gbogbo ìwé ńlá kan, tí yóò sì fún ọ ní kóòdù aláìlẹ́gbẹ́ kan. Bí o bá yí àmì full stop kan péré nínú ìwé náà padà, kóòdù náà yóò yí padà pátápátá. Ṣùgbọ́n kò ṣeé ṣe láti wo kóòdù náà kí o sì mọ ohun tí ìwé àkọ́kọ́ náà sọ. Bitcoin ń lo irú hash kan tí a ń pè ní SHA-256, èyí sì ni ó ń mú gbogbo blockchain ṣiṣẹ́ pọ̀.

## Ní Àpẹẹrẹ

*"Àkọsílẹ̀ kọ̀ọ̀kan ní hásì àkọsílẹ̀ tó ṣáájú rẹ̀"*

**Ìtumọ̀ èyí:** Àkọsílẹ̀ kọ̀ọ̀kan nínú blockchain Bitcoin so pọ̀ mọ́ èyí tó ṣáájú rẹ̀ nípasẹ̀ hásì rẹ̀, ìdánimọ̀ tó yàtọ̀ bí ìtẹ̀ọwọ́. Bí ẹnikẹ́ni bá gbìyànjú láti yípadà ìṣòwò àtijọ́, hásì rẹ̀ yóò yípadà, èyí tó sì ń fọ́ ìsopọ̀ sí gbogbo àkọsílẹ̀ tó tẹ̀lé e. Gbogbo ẹ̀wọ̀n náà yóò fojú kò jẹ́ ohun tó bójú mu lẹ́sẹ̀kẹsẹ̀.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Àwọn hásì ìṣirò ni ohun tó mú kí Bitcoin kò ṣeéṣe láti ṣàtúnṣe. O kò lè yípadà ohun tó ti kọjá láìṣe gbogbo iṣẹ́ náà ní tuntun láti ìpìlẹ̀ yẹn sí òní, àti gbogbo nẹ́tíwọ̀ọ̀kì tó ṣòótọ́ yóò kọ ọ́. Ó jẹ́ ìpele ààbò tó pamọ́ lẹ́yìn gbogbo ohun tí Bitcoin ń ṣe, láti ìfọwọ́sí àwọn ìṣòwò títí ìdáàbòbò àwọn àpamọ́owó.
