# Àdàpọ̀ Awakùsà

**Ẹ̀ka:** Nẹ́tíwọ̀ọ̀kì

## Ìtumọ̀ Rọrùn

Ẹgbẹ́ àwọn awakùsà Bitcoin tó ń papọ̀ agbára ìṣirò wọn láti mú àǹfààní wọn pọ̀ sí i fún gbígba ẹ̀san àkọsílẹ̀, lẹ́yìn náà tí wọ́n ń pín ẹ̀san wọn.

## Àkàwé

Ronú pé ọ̀rẹ́ mẹ́wàá ra tikẹ́ẹ̀tì lottery kan-kọ̀ọ̀kan. Àǹfààní ẹni kọọkan láti ṣẹ́gun kò pọ̀. Ṣùgbọ́n bí wọ́n bá kó owó wọn jọ, tí wọ́n sì ra tikẹ́ẹ̀tì mẹ́wàá pẹ̀lú àdéhùn pé wọ́n máa pín èrè náà, àǹfààní wọn láti ṣẹ́gun yóò pọ̀ sí i, èrè náà sì máa dájú díẹ̀ sí i. Àdàpọ̀ awakùsà ń ṣiṣẹ́ bákan náà. Àwọn awakùsà kékeré ń darapọ̀ mọ́ra kí wọ́n lè gba ẹ̀san kékeré ní ìgbà gbogbo dípò kí wọ́n máa dúró fún ọ̀pọ̀ oṣù tàbí ọdún kí wọ́n tó rí àkọsílẹ̀ kan.

## Ní Àpẹẹrẹ

*"Ọ̀pọ̀ jù lọ àwọn awakùsà Bitcoin lónìí ń ṣiṣẹ́ nípasẹ̀ àdàpọ̀ awakùsà dípò jíjẹ́ awakùsà ní àdáni"*

**Ìtumọ̀ èyí:** Awakùsà alákọ̀ọ́bẹ̀rẹ̀ ṣeéṣe, ṣùgbọ́n ìjàkàdì náà le tó pé awakùsà kan lè gba àkókò pẹ́ jù láìrí àkọsílẹ̀ kankan. Àwọn àdàpọ̀ jẹ́ kí àwọn awakùsà gba owo tó dọ́gba pẹ̀lú agbára ìṣirò tó wọn dá wọlé, kódà bí àdàpọ̀, kì í ṣe awakùsà tó yàtọ̀, ló rí àkọsílẹ̀ náà.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Àwọn àdàpọ̀ awakùsà mú awakùsà Bitcoin di ohun tó ṣeéṣe ní ọrọ̀-ìnáwó fún àwọn awakùsà kékeré. Àmọ́ ṣá, wọ́n tún ń fa àníyàn: bí àdàpọ̀ kan bá ń ṣàkóso agbára ìṣirò nẹ́tíwọ̀ọ̀kì tó tó, ó lè, ní ìmọ̀ ẹ̀kọ́, ṣe ewu ìpínkiri Bitcoin. Nítorí èyí àwùjọ Bitcoin ń ṣó àwọn àdàpọ̀ ní ìmúra àti ìdí tí pínpín hásírèétì káàkiri àwọn àdàpọ̀ ọ̀pọ̀ fi dára fún nẹ́tíwọ̀ọ̀kì.
