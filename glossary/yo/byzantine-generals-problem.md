# Byzantine Generals Problem

**Ẹ̀ka:** Technology

## Ìtumọ̀ Rọrùn

Byzantine Generals Problem jẹ́ ìṣòro nínú game theory àti computer science tó fi hàn bí ó ṣe ṣòro fún nẹ́tíwọ́ọ̀kì tí kò ní olórí àárín gbùngbùn láti dé sí ìpinnu kan náà, pàápàá tí àwọn kan bá ń gbìyànjú láti tan àwọn yòókù jẹ.

## Àkàwé

Ronú pé ọ̀pọ̀ àwọn ọmọ ogun yí ìlú ọ̀tá kan ká, gbogbo wọn sì ní gẹ́ńrẹ́lì tirẹ̀. Wọ́n gbọ́dọ̀ fohùn ṣọ̀kan pé wọ́n máa kọlu tàbí wọ́n máa padà sẹ́yìn ní àkókò kan náà. Bí díẹ̀ bá kọlu, tí àwọn yòókù sì padà sẹ́yìn, wọ́n máa ṣẹ́gun. Ìṣòro náà ni pé wọ́n ń fi àwọn oníṣẹ́ ránṣẹ́ láàárín ara wọn, àwọn gẹ́ńrẹ́lì kan sì lè jẹ́ alátànjẹ tí wọ́n ń fi ìrántí irọ́ tàbí àṣẹ tó yàtọ̀ ránṣẹ́ kí wọ́n lè dá gbogbo ètò rú.

## Ní Àpẹẹrẹ

*"Bitcoin yanjú Byzantine Generals Problem nípasẹ̀ lílo blockchain tí kò ní olórí àárín gbùngbùn pẹ̀lú Proof of Work"*

**What this means:** Bitcoin lo ọ̀pọ̀ ọ̀nà láti jẹ́ kí gbogbo nẹ́tíwọ́ọ̀kì lè fohùn ṣọ̀kan lórí ohun tó jẹ́ òtítọ́.

1. Proof of Work: Bí a ṣe ń fi àpẹẹrẹ àwọn gẹ́ńrẹ́lì náà wé e, gẹ́ńrẹ́lì kọ̀ọ̀kan gbọ́dọ̀ lo agbára kọ̀ǹpútà àti iná mọnámóná púpọ̀ láti yanju ìṣòro ìṣírò kan kí ó tó lè fi "ìrántí" rẹ ránṣẹ́. Èyí mú kí ó ṣòro gan-an fún ẹni búburú láti fi àwọn ìrántí irọ́ kún nẹ́tíwọ́ọ̀kì.
2. Blockchain: Gbogbo àwọn ìfọ̀rọ̀wérọ̀ tí gbogbo ènìyàn ti fara mọ́ ni a kó sínú blocks tí a so pọ̀ pẹ̀lú cryptographic hashes. Gbogbo node ní ẹ̀dà tó jọra ti àkọsílẹ̀ yìí. Bí ẹnikẹ́ni bá gbìyànjú láti yí ohun tó ṣẹlẹ̀ tẹ́lẹ̀ padà, gbogbo nẹ́tíwọ́ọ̀kì yóò rí i lẹ́sẹ̀kẹsẹ̀.
3. Longest Chain Rule: Àwọn nodes máa ń gba chain tó gùn jù lọ, torí pé ó ní ẹ̀rí iṣẹ́ (Proof of Work) tó pọ̀ jù. Bí chains méjì bá fara hàn, gbogbo ènìyàn máa ń tẹ̀lé èyí tí ó ń dagba kíákíá jù. Kí ẹni búburú lè fi chain irọ́ gba gbogbo ènìyàn gbọ́, ó ní láti ní ju ìdá àádọ́ta nínú ọgọ́rùn-ún (50%) agbára mining gbogbo nẹ́tíwọ́ọ̀kì lọ.
4. Ẹ̀san fún Ìwà Òótọ́: Bitcoin ń san miners pẹ̀lú bitcoin tuntun àti transaction fees fún ṣíṣe iṣẹ́ wọn ní òótọ́. Bí miner kan bá ṣe iyanjẹ, àwọn nodes yòókù máa kọ block rẹ̀, gbogbo agbára iná àti kọ̀ǹpútà tó lò yóò sì ṣòfò. Èyí mú kí ó jẹ́ èrè púpọ̀ sí i láti dáàbò bo nẹ́tíwọ́ọ̀kì ju láti gbìyànjú láti kọlù ú.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Lílo Byzantine Generals Problem ló ń ṣàlàyé ìdí tí Bitcoin fi ń lo ọ̀pọ̀ àwọn òfin àti imọ̀-ẹ̀rọ rẹ. Ó fi hàn bí nẹ́tíwọ́ọ̀kì kan ṣe lè ṣiṣẹ́ láìsí olórí àárín gbùngbùn, tí gbogbo àwọn tó wà nínú rẹ̀ sì lè fohùn ṣọ̀kan lórí ohun tó jẹ́ òtítọ́, kódà nígbà tí àwọn kan bá fẹ́ tan àwọn yòókù jẹ.
