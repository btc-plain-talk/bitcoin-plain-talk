# Igi Merkle

**Ẹ̀ka:** Ìmọ̀-ẹrọ

## Ìtumọ̀ Rọrùn

Ìtòlẹ́sẹẹsẹ ìṣirò tó ń kójọ gbogbo àwọn ìṣòwò nínú àkọsílẹ̀ sínú ìdánimọ̀ kan ṣoṣo, tó jẹ́ kó rọrùn láti ṣàyẹ̀wò pé kò sí nǹkan tó yípadà.

## Àkàwé

Fojú inú wo pé o ní àwọn ìwé ìsanwó ọgọ́rùn láti ìrìn àjò ọjà. Dípò ṣíṣàyẹ̀wò ọ̀kọ̀ọ̀kan, o ń kó wọn jọ ní àwọn oríi méjì-méjì, o ń ṣẹda àkọsórí fún joríi kọ̀ọ̀kan, lẹ́yìn náà o ń ṣẹda àkọsórí àwọn àkọsórí náà, títí o fi dé nọ́mbà ìkẹyìn kan tó ṣàpẹẹrẹ gbogbo àwọn ìwé ìsanwó ọgọ́rùn. Bí ẹnikẹ́ni bá yípadà ìwé ìsanwó kankan, nọ́mbà ìkẹyìn yóò yípadà pátápátá. Igi Merkle ń ṣe èyí pátápátá fún àwọn ìṣòwò Bitcoin, ó ń yí ẹgbẹẹgbẹ̀rún ìṣòwò padà sí ìdánimọ̀ kúkú kan tí wọ́n ń pè ní Ìpìlẹ̀ Merkle.

## Ní Àpẹẹrẹ

*"A tọ́jú Ìpìlẹ̀ Merkle nínú àkọlé àkọsílẹ̀ kọ̀ọ̀kan."*

**Ìtumọ̀ èyí:** Àkọsílẹ̀ kọ̀ọ̀kan ní hásì kan ṣoṣo tó jẹ́ ìdánimọ̀ gbogbo ìṣòwò tó wà nínú rẹ̀. Bí ìṣòwò kankan bá yípadà, Ìpìlẹ̀ Merkle yóò yípadà, gbogbo àkọsílẹ̀ náà sì yóò jẹ́ kọ̀ sílẹ̀ lójú nẹ́tíwọ̀ọ̀kì. Bẹ́ẹ̀ ni Bitcoin ṣe ń rí i dájú pé àwọn àkọsílẹ̀ ìṣòwò kò lè ṣàtúnṣe ní àṣírí.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Igi Merkle mú kí Bitcoin ní ìṣiṣẹ́ àti kò ṣeéṣe láti ṣàtúnṣe ní àkókò kannáà. Àpamọ́owó ìmọ̀-ẹrọ kékeré lórí fóònù rẹ kò nílò láti ṣe àgbéwọlé gbogbo ìṣòwò, ó ṣàyẹ̀wò Ìpìlẹ̀ Merkle nìkan láti fìdí pé ìṣòwò kan jẹ́ tòótọ́ múlẹ̀. Nítorí èyí ní o ṣe lè fìdí ìsanwó múlẹ̀ láì ṣe àgbéwọlé gbogbo blockchain.
