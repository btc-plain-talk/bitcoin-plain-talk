# Kọ́kọ́ Àṣírí

**Ẹ̀ka:** Ààbò

## Ìtumọ̀ Rọrùn

Kóòdù àṣírí tó fi hàn pé bitcoin jẹ́ tirẹ tó sì jẹ́ kí o lè lo. Ẹnikẹ́ni tó bá ní kọ́kọ́ àṣírí náà ló ní agbára lórí àwọn owó náà.

## Àkàwé

Rò pé ó dà bí PIN àkọọ́lẹ̀ bánkì rẹ, àfi pé kò sí bánkì láti pè bí o bá gbàgbé rẹ̀, kò sí ẹnikẹ́ni tó lè tún un ṣe fún ọ. Bí ẹlòmíràn bá gba kọ́kọ́ àṣírí rẹ, wọ́n lè gba gbogbo bitcoin rẹ. Bí o bá pàdánù rẹ̀, o pàdánù àǹfààní sí bitcoin rẹ títí láí.

## Ní Àpẹẹrẹ

*"Má ṣe pín kọ́kọ́ àṣírí rẹ fún ẹnikẹ́ni"*

**Ìtumọ̀ èyí:** Kọ́kọ́ àṣírí rẹ ni ọ̀rọ̀ àṣírí àkọ́kọ́ sí bitcoin rẹ. Pínpín rẹ̀ dà bí títẹ̀ àpamọ́owó rẹ gbogbo fún ẹnìkan tí o ń sọ pé "gba ohun tó wù ọ." Kò sí iṣẹ́ tó bójú mu tó máa béèrè fun rẹ̀ rí.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Bitcoin kò ní àtìlẹ́yìn oníbàárà. Kò sí banki tí o lè pè, kò sì sí ẹ̀ka tí yóò dá owó rẹ padà bí a bá tan ọ jẹ. Kọ́kọ́ àṣírí ni ẹ̀rí kan ṣoṣo pé ìwọ ni oní bitcoin náà. Mímú un pamọ́ àti dídáàbò bo ó ni ohun tó ṣe pàtàkì jù lọ nínú ààbò Bitcoin.
