# Ìhà-ẹ̀rọ

**Ẹ̀ka:** Nẹ́tíwọ̀ọ̀kì

## Ìtumọ̀ Rọrùn

Kọ̀ǹpútà tó ń pa adákọ pípé ti blockchain Bitcoin mọ́ tó sì ń ṣàyẹ̀wò pé gbogbo ìṣòwò àti àkọsílẹ̀ ń tẹ̀lé àwọn òfin. Àwọn ìhà-ẹ̀rọ ni wọ́n ń mú kí àwọn òfin Bitcoin ṣiṣẹ́.

## Àkàwé

Ronú pé àwọn ìhà-ẹ̀rọ jẹ́ bí àwọn àgbàlagbà ìlú tí gbogbo wọn ní ẹ̀dà ìwé àkọsílẹ̀ osìṣẹ́. Bí ẹnìkan bá sọ pé ìṣòwò kan ṣẹlẹ̀, gbogbo wọn máa ṣàyẹ̀wò inú ẹ̀dà tiwọn. Bí ẹnikẹ́ni bá gbìyànjú láti yí àkọsílẹ̀ kan padà, àwọn yòókù yóò tètè mọ̀ pé ìtanràn ni. Bí iye àwọn àgbàlagbà ṣe pọ̀ tó, bẹ́ẹ̀ ni ó ṣe ṣòro fún ẹnikẹ́ni láti tan àwọn mìíràn jẹ.

## Ní Àpẹẹrẹ

*"Ṣíṣe àlámọjú ìhà-ẹ̀rọ tirẹ túmọ̀ sí pé o kò ní láti gbẹ́kẹ̀ lé ẹnikẹ́ni míì"*

**Ìtumọ̀ èyí:** Dípò kí o gbẹ́kẹ̀ lé iṣẹ́ ẹni kẹta láti sọ ohun tó wà lórí blockchain fún ọ, o lè ṣàyẹ̀wò ohun gbogbo fúnra rẹ. Ìhà-ẹ̀rọ rẹ máa ń jẹ́rìí pé gbogbo ìṣòwò tí o bá gba jẹ́ gidi, wọ́n sì tẹ̀lé àwọn òfin Bitcoin.

## Ìdí Tí Ó Fi Ṣe Pàtàkì

Àwọn ìhà-ẹ̀rọ ni ẹ̀yìn ìpínkiri Bitcoin. Kò sí node kankan tó jẹ́ olórí àwọn yòókù. Gbogbo wọn ni wọ́n ń fi òfin kan náà ṣiṣẹ́ lọ́tọ̀ọ̀tọ̀. Èyí túmọ̀ sí pé kò sí ibi kan ṣoṣo tí a lè kọlu, rà, tàbí pa, èyí tó mú kí Bitcoin lè dojú kọ ìdènà.
